# AI DATA CENTER TYCOON — 1차 테스트판

배포 식별자: `playtest-01` / 게임 내부 버전: `0.6.0-rc1` / 저장 형식: v3

정식 출시판이 아닌 피드백 수집용 테스트 빌드입니다. 이번 배포에 포함된 파일의 SHA-256과 manifest가 정확한 빌드 식별 기준입니다. 기존 버전과 내부 버전 문자열이 같으므로 오류 제보에는 반드시 `playtest-01`을 적어 주세요.

## Windows 실행

1. Windows ZIP을 새 폴더에 **전체 압축 해제**합니다.
2. `AIDataCenterTycoon.exe`를 실행합니다. 같은 폴더의 `.pck` 파일을 분리하지 마세요. Godot 편집기나 Python 설치는 필요 없습니다.
3. 이 빌드는 Windows x86_64용 무설치 ZIP이며, 설치 마법사와 코드 서명은 없습니다. 보안 경고가 발생하면 배포자와 파일 해시를 확인하세요. 백신이나 운영체제 보안 기능을 끄지 마세요.

## Web 실행

테스터는 배포자가 제공한 웹 주소에서 실행합니다. ZIP의 `index.html`을 더블클릭하는 file:// 실행은 지원하지 않습니다.

배포자 로컬 확인: Web ZIP을 압축 해제한 폴더에서 Python이 설치되어 있다면 다음 명령 실행 후 `http://127.0.0.1:8138`에 접속합니다.

```powershell
python -m http.server 8138 --bind 127.0.0.1
```

외부 호스팅은 ZIP 루트의 index.html과 모든 파일을 함께 배치해야 합니다. HTTPS 호스팅에서 실제 로딩·음성·저장 복원을 확인한 다음 URL을 전달하세요. 이 문서는 외부 업로드 완료를 의미하지 않습니다.

## 조작과 테스트 순서

- 새 게임 → 튜토리얼 → 건설 메뉴에서 설비 배치 → 공사 완료 → 설비 선택·운전 모드 변경.
- 냉각·전력 공급을 확인하고 계약을 수락·진행·완료하거나 취소합니다.
- 연구 창에서 잠금/미연구/완료 표시와 구매 직후 TP 차감을 확인합니다.
- 상단 일시정지·배속, 설정의 언어·음량을 확인합니다. Esc로 운영 메뉴를 엽니다.
- 수동 저장 후 종료·재실행·이어하기로 진행 상태가 유지되는지 확인합니다.
- 1280×720과 1600×900, 한국어·영어에서 글자/아이콘/버튼 잘림을 확인합니다.

## 저장과 제한

- 중요한 기존 세이브는 테스트 전에 백업하세요. 새 게임·수동 저장이 기존 저장에 영향을 줄 수 있습니다.
- Windows 저장은 게임 ZIP과 별도의 Godot 사용자 데이터 영역에 보관됩니다. 일반 경로는 `%APPDATA%\Godot\app_userdata\AI Data Center Tycoon`입니다. 오류 보고에 사용자 폴더 전체를 첨부하지 마세요.
- Web 저장은 브라우저·사이트 주소별로 분리되며 사이트 데이터 삭제, 시크릿 모드, 저장 차단 설정 등에 따라 사라질 수 있습니다. Windows와 Web 저장이 자동 동기화되지는 않습니다.
- 장시간 밸런스, 다른 PC의 그래픽/음성, Web 새로고침 후 저장 지속성은 배포 전·중 추가 검수 대상입니다. 모바일은 테스트 대상이 아닙니다.
- 일부 그래픽은 AI 공동 제작 에셋입니다. 외부 구성요소 고지는 동봉된 THIRD_PARTY_NOTICES.txt와 FONT_LICENSE.txt를 참고하세요.
